⚙️ Подключение ИИ

Выберите агента — ключи настраиваются один раз в прокси (как подключить), в приложение они не вводятся

Прямой вызов GigaChat/YandexGPT из браузера блокируется CORS, поэтому нужен единоразовая настройка прокси (~5 минут).

1. Откройте dash.cloudflare.com → зарегистрируйтесь (бесплатно, без карты)
2. Workers & Pages → Create Worker → Deploy
3. «Edit code» → удалите весь код → вставьте код из файла worker.js (в репозитории приложения) → Deploy
4. Settings → Variables and Secrets → добавьте секрет GIGACHAT_KEY — Authorization Key с developers.sber.ru (или YANDEX_API_KEY + YANDEX_FOLDER_ID с cloud.yandex.ru)
5. Скопируйте URL вида https://имя.workers.dev в поле «URL прокси» выше

Всё: в приложении остаётся только выбрать агента. Проверить настройку можно, открыв URL прокси в браузере.
