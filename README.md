# МоёПортфолио — мини-приложение для MAX

Мини-приложение для мессенджера MAX: централизованное хранение грамот, сертификатов,
дипломов и других свидетельств об участии в конкурсах и мероприятиях.

**Опубликовано:** https://vladimirsokolov10007-creator.github.io/moeportfolio-max/

## Возможности

- 📚 Хранение документов с фото, категориями, датами и описанием (данные — на устройстве пользователя, `WebApp.DeviceStorage` / `localStorage`)
- 🔍 Поиск и просмотр портфолио
- 📄 Формирование единого PDF со всеми наградами (по одной странице А4 на документ + титульный лист)
- 🤖 **Резюме с помощью ИИ** — составление резюме из достижений через GigaChat (Сбер) или YandexGPT (Яндекс)
- 📤 Интеграция MAX Bridge: профиль пользователя, кнопка «Назад», тактильные отклики, шеринг

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | Само мини-приложение (единый файл: HTML + CSS + JS) |
| `worker.js` | Cloudflare Worker — прокси для вызова ИИ из браузера (обход CORS) |
| `server.js` | Локальный сервер для предпросмотра (`npm run dev`) |
| `test-worker.cjs` | Тест логики worker.js (моки GigaChat/YandexGPT) |
| `mock-proxy.cjs` | Мок-прокси для теста приложения без реальных ключей |

## Настройка ИИ-функции (резюме)

Прямой вызов GigaChat/YandexGPT из браузера блокируется CORS, поэтому нужен
бесплатный прокси (Cloudflare Worker, ~5 минут, без банковской карты):

1. Зарегистрируйтесь на **dash.cloudflare.com** → Workers & Pages → Create Worker → Deploy
2. «Edit code» → удалите весь код → вставьте содержимое `worker.js` → Deploy
3. Скопируйте URL вида `https://<имя>.workers.dev`

**Ключ GigaChat** (вариант по умолчанию):

1. Зарегистрируйтесь на **developers.sber.ru**
2. Создайте проект → подключите GigaChat API
3. Скопируйте **Authorization Key** (Base64 от Client ID:Client Secret)

**Ключ YandexGPT** (альтернатива):

1. Зарегистрируйтесь на **cloud.yandex.ru**, создайте сервисный аккаунт с ролью `ai.languageModels.user`
2. Создайте **API-ключ** сервисного аккаунта
3. Скопируйте **Folder ID** каталога

В приложении: экран «🤖 Резюме» → «Настройки ИИ» → выберите провайдера,
вставьте ключ и URL прокси → «Сохранить». Ключи хранятся только на устройстве
(в MAX — в защищённом хранилище `SecureStorage`).
