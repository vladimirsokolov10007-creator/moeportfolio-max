# МоёПортфолио — мини-приложение для MAX

Мини-приложение для мессенджера MAX: централизованное хранение грамот, сертификатов,
дипломов и других свидетельств об участии в конкурсах и мероприятиях.

**Опубликовано:** https://vladimirsokolov10007-creator.github.io/moeportfolio-max/

## Возможности

- 📚 Хранение документов с фото, категориями, датами и описанием (данные — на устройстве пользователя, `WebApp.DeviceStorage` / `localStorage`)
- 🔍 Поиск и просмотр портфолио
- 📄 Формирование единого PDF со всеми наградами (по одной странице А4 на документ + титульный лист)
- 📝 **Резюме из достижений** — автоматическое составление резюме по шаблонам: цель, главное достижение, достижения по категориям, ключевые навыки, блок «О себе», статистика. Работает полностью офлайн — без интернета, регистраций, ключей и сторонних сервисов
- 📤 Интеграция MAX Bridge: профиль пользователя, кнопка «Назад», тактильные отклики, шеринг

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | Само мини-приложение (единый файл: HTML + CSS + JS) |
| `server.js` | Локальный сервер для предпросмотра (`npm run dev`) |

## Запуск локально

```bash
npm run dev        # http://localhost:7100
```
